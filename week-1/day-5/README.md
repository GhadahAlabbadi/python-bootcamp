# Week 1 - Day 5

## Overview

The fifth day focused on advanced PowerShell concepts, Git workflows, and best practices for managing changes safely. The session also included a roadmap presentation summarizing the topics covered during the first week.

---

## Topics Covered

- PATH and Environment Variables
- Aliases and Shell Configuration
- Command Chaining
- Conditions and Loops in PowerShell Scripts
- Executable Scripts and Permissions
- Git's Four Areas
- Inspecting Changes Before Committing
- Undoing Mistakes Safely
- Complete Branch Lifecycle
- Merge Conflicts
- Fetch vs Pull

---

## Key Concepts

### PATH and Environment Variables

Learned how environment variables work and how the PATH variable allows commands and applications to be executed from any directory.

### Aliases and Shell Configuration

Learned how aliases simplify frequently used commands and how shell configuration files can customize the PowerShell environment.

### Command Chaining

Practiced combining multiple commands using operators such as:

- &&
- ||
- ;

### Conditions and Loops

Learned how to automate repetitive tasks using:

- if
- foreach
- for
- while

inside PowerShell scripts.

### Executable Scripts

Learned how PowerShell executes .ps1 files and how execution policies affect script permissions.

### Git's Four Areas

Reviewed the Git workflow:

- Working Directory
- Staging Area
- Local Repository
- Remote Repository

### Inspect Changes Before Committing

Used Git commands to review changes before creating commits.

### Undo Mistakes Safely

Practiced safe methods for restoring files, unstaging changes, and reverting commits.

### Complete Branch Lifecycle

Reviewed the full lifecycle of a Git branch:

- Create
- Switch
- Commit
- Merge
- Delete

### Merge Conflicts

Learned what merge conflicts are and how they occur when different changes affect the same lines of code.

### Fetch vs Pull

Compared:

- git fetch
- git pull

and understood when each command should be used.
