# Week 1 - Day 2

## Overview

The second day focused on learning the fundamentals of the Command Line Interface (CLI) and Git. The session covered essential commands, file navigation, Git workflows, and practical exercises using a simple project.

---

## Topics Covered

- CLI (What, Why, Operations)
- Git (What, Why, Operations)
- Common CLI Commands
- Useful CLI Tips
- Relative vs Absolute Paths
- Running Python Programs
- Essential Git Commands

---

## Key Concepts

### Command Line Interface (CLI)
Learned what the CLI is, why it is important, and how to perform common file and directory operations.

### Git
Introduced to Git as a version control system, including its purpose and basic workflow.

### Common CLI Commands
Practiced common commands such as:
- mkdir
- ni
- cd
- ls
- pwd
- clear

### Relative vs Absolute Paths
Learned the difference between navigating using relative paths and absolute paths.

### Running Python
Learned how to execute Python programs from the terminal.

Example:
python main.py

### Essential Git Commands
Practiced the basic Git workflow using commands such as:

- git init
- git status
- git add
- git commit
- git log
