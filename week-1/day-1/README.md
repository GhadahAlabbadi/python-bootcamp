## Overview

The first day of the Python Bootcamp focused on introducing the course structure, development tools, and fundamental concepts that will be used throughout the bootcamp.

---

## Topics Covered

- Command Line Interface (CLI)
- Django (Introduction)
- PEP 8 (Python Style Guide)
- GIGO (Garbage In, Garbage Out)
- Git (Introduction)
- GitHub (Introduction)
- IDEs and Anaconda
- Python 2 vs Python 3

---

## Key Concepts

### Command Line Interface (CLI)
Learned the basics of interacting with the operating system through terminal commands.

### Django
An overview of the Django web framework and its role in Python web development.

### PEP 8
Introduced to the official Python coding style guide and the importance of writing clean, readable code.

### GIGO
Learned the concept of Garbage In, Garbage Out, which means incorrect input leads to incorrect output.

### Git & GitHub
A general introduction to version control, repositories, and collaboration using GitHub.

### IDEs & Anaconda
Overview of common Python development environments and the Anaconda distribution.

### Python 2 vs Python 3
A brief comparison between Python 2 and Python 3, highlighting that Python 3 is the modern version with improved syntax, better Unicode support, and ongoing development, while Python 2 is no longer officially supported.
