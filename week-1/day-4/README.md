## Key Concepts

### What is GitHub?

GitHub is a cloud-based platform that hosts Git repositories and enables developers to collaborate, manage projects, review code, and track changes.

### Why Developers Use GitHub

- Version control
- Team collaboration
- Backup for source code
- Code reviews
- Project management
- Open-source contributions
- CI/CD integration

### GitHub License

A license defines how other people can use, modify, and distribute your project.

### GitHub Actions (CI/CD)

GitHub Actions is GitHub's built-in automation platform used to automate workflows such as:

- Running tests
- Building applications
- Deploying projects
- Continuous Integration (CI)
- Continuous Deployment (CD)
