## Key Concepts

### Loops

Loops eliminate repetitive code by defining a rule that repeats a block of statements. Each repetition is called an iteration.

### for Loop

The for loop repeats code for each item in a sequence such as a string, list, or range.

### range()

Practiced the different forms of range():

- range(stop)
- range(start, stop)
- range(start, stop, step)

Also learned how to count both forward and backward.

### Iterating Through Strings

Used for loops to process one character at a time from a string.

### Iterating Through Collections

Used for loops to iterate through collections such as lists.

### Conditions Inside Loops

Combined conditional statements with loops to control program behavior during each iteration.

### Counters

Used counters to record how many times an event occurs.

### Accumulators

Used accumulators to build a result gradually during repeated iterations.

### while Loop

Used while loops when the number of iterations depends on a condition rather than a fixed sequence.

### Choosing Between for and while

Learned when to use:

- for for known or iterable repetitions.
- while for condition-based repetition.

### Input Validation

Used while loops to repeatedly request user input until valid data is entered.

### Exit Strategy

Learned that every while loop must include a condition that eventually becomes False to avoid infinite loops.

### break

Used break to exit a loop immediately.

### continue

Used continue to skip the current iteration and move directly to the next one.

### pass

Used pass as a placeholder to keep an empty block syntactically valid.

### Nested Loops

Used nested loops to perform repeated operations at multiple levels.

### Menu-Driven Programs

Introduced menu-based programs that combine loops and conditions to allow users to repeatedly choose program options.

### Common Loop Mistakes

Reviewed common loop errors involving:

- Incorrect range() usage
- Infinite while loops
- Incorrect indentation
- Invalid loop conditions

### White Box Testing

Introduced White Box Testing, which verifies the internal logic and code paths of a program.

### Black Box Testing

Introduced Black Box Testing, which verifies program behavior by checking inputs and outputs without examining the internal implementation.
