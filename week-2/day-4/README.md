## Key Concepts

### Conditions

Conditions control the execution path of a program by allowing different code to run based on whether a condition evaluates to True or False.

### if Statement

The if statement executes a block of code only when its condition is True.

### else Statement

The else statement provides the alternative execution path when the if condition is False.

### elif Statement

The elif statement allows multiple conditions to be checked sequentially without nesting several if statements.

### First True Branch Wins

Python evaluates conditions from top to bottom and executes only the first condition that evaluates to True.

### Nested Conditions

Nested conditions allow one decision to depend on another by placing an if statement inside another if statement.

- Outer Decision – evaluated first.
- Inner Decision – evaluated only if the outer condition is satisfied.

### Logical Operators

Used to combine multiple conditions.

- and
- or
- not

### Truthy and Falsy Values

Learned that many values can be evaluated directly as Boolean values using Python's truth-testing rules.

### bool()

The bool() function converts values into either True or False.

### Input Validation

Validated user input before processing it to prevent runtime errors and improve program reliability.

### Text Validation Methods

Practiced using:

- isalpha()
- isdigit()
- isalnum()

to validate different types of text input.

### Numeric Validation

Validated numeric input before converting strings into integers using int().

### Range and Choice Validation

Checked whether user input falls within acceptable ranges or predefined choices.

### Conditional Expressions

Used Python's conditional (ternary) expression to write simple conditions in a compact form.

### match Statement

Introduced Python's match statement for handling fixed-choice branching more clearly than multiple elif statements.

### Common Conditional Errors

Identified common mistakes including:

- Incorrect conditions
- Improper indentation
- Incorrect logical operators
- Invalid program structure
