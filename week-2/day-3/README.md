## Key Concepts

### Expressions

Expressions combine values, variables, operators, and functions to produce a single result.

### Arithmetic Operators

Practiced using:

- `+`
- `-`
- `*`
- `/`
- `//`
- `%`
- `**`

to perform mathematical operations.

### Division Operators

Learned the differences between:

- / → True Division
- // → Floor Division
- % → Modulus (Remainder)

and when each operator should be used.

### Operator Precedence

Learned how Python determines the order in which expressions are evaluated and how parentheses can override the default precedence.

### Assignment Operators

Practiced updating variables using assignment operators such as:

- =
- +=
- -=
- *=
- /=

### Comparison Operators

Used comparison operators to produce Boolean (`True` / `False`) results.

### Boolean Logic

Combined conditions using:

- and
- or
- not

to create more complex logical expressions.

### Membership Operators

Checked whether a value exists within a sequence using:

- in
- not in

### Identity Operators

Learned how is and is not compare object identity rather than values.

### Equality vs Identity

Compared the difference between:

- == (value comparison)
- is (object identity comparison)

### String Indexing and Slicing

Accessed individual characters using indexing and extracted ranges of characters using slicing.

### String Methods

Practiced common string methods including:

- strip()
- lower()
- upper()
- replace()
- startswith()
- endswith()
- split()
- find()
- join()

### split() and join()

Learned how to split text into multiple strings and join multiple strings into a single string.

### String Immutability

Learned that strings are immutable, meaning string operations always return new string objects.

### Object Identity

Learned that variables store references to objects and that an object's identity is independent of the variable name referencing it.

### Labels and Values in RAM

Introduced to how Python variables reference objects stored in memory rather than directly storing values.
